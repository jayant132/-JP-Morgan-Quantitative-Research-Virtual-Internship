JP Morgan Quantitative Research Virtual Internship

📌 Overview

This project was completed as part of the JP Morgan Quantitative Research Virtual Internship, focused on commodity market analysis and quantitative data modeling. The task involved analyzing commodity price data and building a pricing model capable of estimating past and future prices based on date inputs.
The project demonstrates practical skills in data analysis, financial modeling, and Python programming used in quantitative research workflows.

🎯 Objectives


Understand commodity storage contracts and pricing concepts


Analyze historical commodity market data


Build a pricing estimation model using Python


Generate past and future price predictions based on date input
